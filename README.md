业务逻辑（采集 / 剪辑 / 发布 / 申诉 / 企微互通）
原样保留，Tkinter 界面 1:1 重做成网页，Chrome 浏览器跑在容器里的虚拟屏幕上，网页里可以直接看到、
可以操作（扫码登录、人工接管脚本都和原来一样）。

## 界面入口

| 入口 | 地址 | 用途 |
|---|---|---|
| 操作界面 | http://localhost:8000 | 和桌面版一样的四个页面 + 设置 + 企微互通 |
| 浏览器画面 | http://localhost:6080/vnc.html | 容器里的 Chrome 画面（也可在界面里点「浏览器画面」） |
| 企微回调 | http://你的IP:8443/wecom | 配置企微互通远程指令时填到企微后台 |


## 容器里装了什么

- **Chromium**：被脚本 CDP 接管的浏览器，每个账号独立 user-data-dir（和桌面版一样的隔离方式）
- **Xvfb + x11vnc + noVNC**：虚拟屏幕，让 Chrome 窗口在网页里可见、可点击
- **ffmpeg**：剪辑用（剪辑模块自动使用，无需配置）
- **中文字体（Noto CJK）**：保证 Chrome 里抖音页面正常渲染中文

## 企微远程指令

配好「企微互通」的回调（Token / AESKey / CorpID + 8443 端口可达 + 允许成员）后，在企微里发消息即可控制：

| 指令 | 作用 |
|---|---|
| `状态` | 回：各账号今日已发/剩余、待发布成品数、任务是否在跑 |
| `发布` | 按网页里当前配置**立即**发布（全部账号 × 全部待发布成品） |
| `定时发布 11-25 07:00` | 现在开跑，但每条作品在抖音后台设成该时间**定时发布** |
| `采集` | 一键采集 + 剪辑（用当前商品清单） |
| `剪辑` | 只补剪成品数量不够的商品 |
| `申诉` | 回一份待申诉清单，回复 **`确认`** 才真正提交（10 分钟内有效，`取消` 放弃） |
| `停止` | 停止发布 / 素材任务 |
| `帮助` | 回指令说明 |

**定时只认绝对时间**，不支持"明天""3 天后"这类相对说法：

- `定时发布 11-25 07:00`、`定时发布 11月25日 7:00`、`定时发布 2026-11-25 07:00` 都可以
- 不写年份 = 今年；只写 `07:00` = 今天（已过会提示补日期）
- 抖音后台限制：最多提前 **14 天**，超了会直接回提示
- 写错时间会回一条说明（例如"时间看不懂。格式：定时发布 11-25 07:00"），不会瞎猜

发布失败、批次结束、申诉结果都会自动推回群里。

## 申诉材料怎么放

设置里的「申诉材料目录」（默认 `data/申诉材料`）就是材料根目录，按下面放：

```
申诉材料/
  ├─ 账号A01/          ← 每个账号一个子目录（命名 = 「账号」+ 账号名）
  ├─ 账号A02/
  └─ …
```

- **只认图片**：`jpg / jpeg / png / webp / bmp`，一般放肖像授权书、资质截图等 1~5 张
- **上传顺序 = 文件名顺序**：用数字前缀控制，如 `1_授权书.jpg`、`2_身份证.png`
- **按规则分目录**：申诉规则可设「材料子目录」，设置了就放 `申诉材料/<子目录>/账号A01/`；不设就直接用 `申诉材料/账号A01/`
- 目录为空的账号程序会**拒绝提交**并写日志提示，不会瞎申诉
- 「清除已发布素材」删的是素材输出里的商品目录，**不影响申诉材料**
